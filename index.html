Вопросы

Частые вопросы

Сколько стоит?
Панель бесплатна. Используется для управления собственным приватным сервером.
Какие системные требования?
Windows 10 или 11, ~50 МБ на диске. Панель лёгкая — Rust + Tauri, без браузера.
Безопасно ли хранить секреты?
Да. Все секреты шифруются через DPAPI Windows — привязаны к пользователю и машине. В логи не попадают.
Можно ли управлять несколькими серверами?
Да. Профили серверов переключаются в настройках. Для каждого — свой набор адресов и секретов.
Есть ли восстановление после сбоя?
Да. Бэкапы БД по расписанию, восстановление балансов Claudium в один клик. Конфликт-детект защищает от потери настроек.
