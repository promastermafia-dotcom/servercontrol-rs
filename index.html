Возможности

15 вкладок — весь сервер под контролем

Полный операторский цикл: от дашборда до восстановления базы данных.

📊

Дашборд

Главный экран состояния — всё на одном взгляде.

  • онлайн / лимит, мир, livez / readyz
  • CPU сервера и хоста, RAM, диск, heap
  • спарклайны за сутки, пиковые значения
  • тикрейт p95 / max, флаг превышения budget
  • скорость канала, возраст бэкапа
  • быстрый (5 с) и медленный (30 с) опросы
👥

Игроки онлайн

Таблица с фильтрами и карточка в отдельном окне.

  • сортировка, фильтры, группировки
  • карточка: статы, спека, титулы, экипировка, таланты
  • страна, город, провайдер по IP (GeoLite2)
  • ЛС / кик / бан из строки
  • отслеживание игрока
  • копирование IP / PID / ника, экспорт CSV
🗺

Карта зон

Игровая карта континента с живыми данными.

  • зоны по игровой проекции с уровнями
  • точки игроков (только открытие мира)
  • открытые порталы с рангом
  • зум, сдвиг, список зон с владельцами
📜

Логи сервера

Семь логов с удобным просмотром и фильтрами.

  • игровой, лаунчер, аудит, PostgreSQL, мосты
  • фильтр по уровню и категории
  • перевод RU / EN, поиск
  • режим «следить», разворот key=value
  • копирование, сохранение, экспорт всех логов
🎮

Управление сервером

Закрытый набор команд — безопасно и предсказуемо.

  • стоп / старт / рестарт листенера
  • бэкап БД (pg_dump), список, удаление, prune
  • восстановление БД и балансов Claudium
  • рестарт / стоп экономики, PostgreSQL
  • ротация и чистка логов (белый список)
  • плановый рестарт с отсчётом и отменой
  • бэкап и рестарт по расписанию
  • баны: выдача / снятие, бан по имени с киком
🛡

Антибот

Живые данные сервера, никаких выдуманных чисел.

  • таблица подозрительных с уликами и картой
  • 7 секций конфигурации детектора
  • IP-бан, чит-марк
  • блокировка от мировых квестов (мягче бана)
  • похожие ники, реплики по подстрокам
  • топы экономики, калибровка, CSV
📢

Новости сервера

Rich-text объявления с картинкой и расписанием.

  • жирный, курсив, подчёркивание, цвет
  • картинка 640×160 до 24 КБ (сжатие на лету)
  • всем / зона / гильдия, защита от дублей
  • шаблоны, черновик, «последнее отправленное»
  • расписание объявлений (интервалы, дни недели)
  • журнал доставки
💬

Чат

Игровая переписка с уведомлениями и быстрыми ответами.

  • фильтр по каналу и собеседнику
  • непрочитанные, звук, онлайн-статус
  • ЛС живому игроку, кик / бан из строки
  • шаблоны быстрых ответов, игнор / блок
💰

Экономика

Полный контроль над Claudium и магазином.

  • аккаунты и балансы Claudium
  • начисление / списание с леджером
  • каталог цен, ручные перебития, сброс
  • леджер с фильтрами, магазин, владения
  • топы трат / предметов, иконки
  • CSV-выгрузки
🌀

Порталы и ивенты

Открытые порталы с таймерами и координатами.

  • таймеры и координаты
  • копирование строки портала в буфер
  • журнал событий
📈

Графики

Фоновый сэмплер пишет историю в CSV (60 с).

  • 4 серии: игроки, CPU, RAM, диск + пинг
  • диапазоны, дневные сводки
  • онлайн по часам, доход Claudium
  • экспорт
🛒

Заявки магазина

Одобрение с начислением и анонсом.

  • чтение / запись заявок
  • одобрение с начислением и анонсом
  • отклонение, удаление
🔍

Аудит

Чтение audit.log с фильтрами и статистикой.

  • фильтры по источнику и действию
  • топ IP, топ действий
  • подсветка нового, экспорт CSV
⚙

Настройки

Профили серверов, секреты, расписания.

  • профили нескольких серверов (переключение)
  • секреты зашифрованы DPAPI Windows
  • темы, пороги алертов, авто-рестарт
  • все расписания, дневной отчёт в webhook
  • защита от потери: конфликт-детект
🌐

Grafana

Ссылка на админскую страницу сервера.

  • открытие встроенной Grafana
