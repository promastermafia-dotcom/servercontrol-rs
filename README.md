# ServerControl RS

Профессиональная настольная панель управления приватным игровым сервером World of Claudecraft.

Всё, что нужно оператору — в одном окне: мониторинг, модерация, экономика, новости, бэкапы.

## Возможности

- **Дашборд** — онлайн, CPU, RAM, диск, тикрейт, спарклайны
- **Игроки онлайн** — карточки, страна по IP, ЛС / кик / бан
- **Карта зон** — живая карта с точками игроков
- **Логи** — 7 логов с фильтрами и поиском
- **Управление** — бэкапы, восстановление, плановый рестарт, расписание
- **Антибот** — подозрительные с уликами, конфигурация детектора
- **Новости** — rich-text объявления с расписанием
- **Чат** — переписка с уведомлениями
- **Экономика** — балансы, гранты, каталог цен, леджер
- **Графики** — история метрик за любой период
- **Аудит** — журнал действий с фильтрами

## Стек

Rust + Tauri 2 + React 19 + TypeScript
