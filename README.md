# ServerControl RS

Настольная панель управления приватным сервером World of Claudecraft для Windows 10/11.

**Стек:** Rust · Tauri 2 · React 19 · TypeScript · PostgreSQL

[![Страница](https://img.shields.io/badge/Страница-promastermafia--dotcom.github.io-blue)](https://promastermafia-dotcom.github.io/servercontrol-rs/)
![Версия](https://img.shields.io/badge/версия-0.7.37-yellow)

## Что умеет

15 вкладок, 106 команд, 1149 тестов, 0 уязвимостей.

| Вкладка | Что делает |
|---|---|
| Дашборд | Онлайн, CPU, RAM, тикрейт, спарклайны |
| Игроки | Таблица, карточка, геолокация по IP, кик/бан |
| Карта зон | Живая карта, игроки, порталы |
| Логи | 7 логов, фильтры, поиск, экспорт |
| Управление | Стоп/старт, бэкапы, восстановление БД, плановый рестарт |
| Антибот | Детектор, подозрительные, IP-бан, блокировка мировых квестов |
| Новости | Rich-text объявления с картинкой и расписанием |
| Чат | Переписка, ЛС, быстрые ответы |
| Экономика | Claudium, каталог, леджер, магазин |
| Графики | История CPU, RAM, онлайн, пинг |
| Прочее | Порталы, заявки, аудит, настройки, Grafana |

## Безопасность

Полный аудит 0.7.37: 14 уязвимостей исправлено, 0 осталось. Секреты зашифрованы DPAPI Windows. Закрытый набор команд.
