# ServerControl RS — для разработчика

Привет! Хочу показать проект — **ServerControl RS**, панель управления приватным игровым сервером World of Claudecraft.

**Что это:** десктопное приложение для Windows 10/11, полностью заменяющее ручное управление сервером. Один оператор закрывает весь цикл: мониторинг, модерация, экономика, бэкапы, логи.

**Стек:**
- **Rust** (Tauri 2) — бэкенд, IPC, шифрование
- **React 19 + TypeScript** — фронтенд (15 вкладок)
- **PostgreSQL** — база сервера

**Цифры:**
- 15 вкладок, 106 команд
- 424 Rust-теста + 725 фронт-тестов (всего 1149)
- Полный аудит безопасности: 14 уязвимостей исправлено, 0 осталось
- cargo audit — 0 уязвимостей

**Что внутри:**
- Дашборд с живыми метриками (CPU, RAM, тикрейт, спарклайны)
- Таблица игроков с геолокацией по IP (GeoLite2)
- Карта зон с игроками и порталами
- 7 логов с фильтрами и поиском
- Управление: стоп/старт, бэкапы pg_dump, восстановление БД, плановый рестарт
- Антибот: детектор, IP-бан, блокировка мировых квестов
- Экономика Claudium: балансы, леджер, магазин
- Rich-text новости с расписанием
- Секреты зашифрованы DPAPI Windows

**Страница возможностей:** https://promastermafia-dotcom.github.io/servercontrol-rs/

Исходники не публикую, но если интересно — могу рассказать про архитектуру, как устроена IPC-цепочка Tauri, или про находки аудита.
